# 🧠 **CS Fundamentals**

Welcome to **CS Fundamentals**: the foundations everything else is built on.

Frameworks come and go; the ideas underneath them don't. This is where I go back to basics: how a computer actually runs a program, how memory works, why an algorithm is fast or slow, and how to think about problems before writing a single line of code.

I'm working through these with [CS50](https://cs50.harvard.edu/x/) and the [Teach Yourself CS](https://teachyourselfcs.com/) path, and logging what sticks along the way.
